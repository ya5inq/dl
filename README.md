# Infinite Media Player — liens courts

Ce dépôt ne contient que les fichiers d'installation de l'application, sous
des noms courts, pour pouvoir être téléchargés depuis une télévision sans
ordinateur.

| Fichier | Pour qui |
|---|---|
| [`arm64.apk`](https://ya5inq.github.io/dl/arm64.apk) | Android TV, Fire TV 64 bits (`arm64-v8a`) |
| [`armv7.apk`](https://ya5inq.github.io/dl/armv7.apk) | Fire TV 32 bits (`armeabi-v7a`) |

Les sommes de contrôle sont dans [`SHA256SUMS`](https://ya5inq.github.io/dl/SHA256SUMS).

Sur la télévision : application **Downloader** (Amazon Appstore) → *Enter URL* →
l'adresse ci-dessus → *Download* → puis ouvrir le fichier téléchargé et
installer.

La page complète est ici :
https://ya5inq.github.io/infinite-media-player-site/telecharger.html
